# Equipment image sources

Artwork downloaded from the Bit Heroes Wiki on 2026-10-03. Local PNGs preserve the original sprites; no artwork was generated. Game artwork belongs to its respective owners.

532 unique local sprites are mapped to 1,029 workbook records (including repeated enchant slots and legacy Evolvium variants). The machine-readable manifest records each item, slot, local asset and original URL.

## Matching rules

Set sprites match both the set name and equipment slot. Workbook abbreviations and spelling variations are explicitly matched to the wiki names. Ancients use the sprite shown for that named Ancient, including the wiki's shared representation for reforge variants. Enchant choices use the wiki's common Mythic enchant icon; their selected bonuses stay in text. Rune pages supply generic random Legendary icons rather than the individual selected rune artwork, so those have not been substituted for specific runes.

The combined Peach / Deano / Spomder workbook choice has no single matching sprite. Rune artwork remains unavailable for specific selections.
